# bad-apple-releases

Public release artifacts for Bad Apple, a sovereign, local AI operating-system
layer for macOS.

## Install

The easiest install is via Homebrew:

```bash
brew tap savageAZfck/bad-apple https://github.com/savageAZfck/homebrew-bad-apple
brew install --cask bad-apple
```

Or download the latest `Bad_Apple-<version>-unsigned.zip`, unzip it, and run:

```bash
sudo ./install.sh
```

See the [release notes](https://github.com/savageAZfck/bad-apple-releases/releases).
